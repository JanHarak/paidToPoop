# Profil a oddělení kalkulačky od deníku Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Přidat profil (přezdívka, avatar, sazba pro deník) jako vrstvu z ikony vpravo nahoře, zápisy ze stopek počítat z profilu a kalkulačku vrátit k samostatnému odhadu se dvěma záložkami „Kalkulačka“ a „Deník“.

**Architecture:** Čistá logika profilu v novém bloku `<script id="profil-logika">` (`window.ProfilLogika`) s testy v Node. UI profilu v novém bloku `<script id="profil-ui">` (`window.Profil`) hned za ním, tedy před nepojmenovaným skriptem kalkulačky, který `window.Profil` používá. Vrstva se otevírá přes existující `window.Vrstvy`.

**Tech Stack:** jeden soubor `index.html` (HTML, CSS, JS ve stylu ES5), testy `node --test` přes `tests/load-block.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-16-profil-design.md` (navazuje na `docs/superpowers/specs/2026-11-15-denik-design.md`).

## Global Constraints

- Vše v `index.html`, ES5 (`var`, `function`, žádné arrow funkce, `let`, `const`, template stringy) v kódu stránky. Testy mohou být moderní JS.
- Česky v UI, mobile-first, světlý i tmavý režim jen přes existující CSS proměnné (`--ink`, `--porcelain`, `--tile`, `--line`, `--shadow` …).
- Nikde znak U+2014 (dlouhá pomlčka), ani v kódu, komentářích, textech a commit zprávách.
- Testy: `node --test` bez argumentu (spouštěj z kořene repa), všechny musí projít.
- Klíč profilu `zachodova-profil-v1`, tvar `{ prezdivka, avatar, mode, castka, mena, hodiny, dni }`.
- Avatary přesně: `🧻 🚽 👑 🦆 💩 🐻 🦄 🚀` a „Žádný“ (prázdný řetězec).
- Přezdívka nejvýš 24 znaků.
- Uložené zápisy deníku se nikdy nepřepočítávají.
- Commit zprávy končí řádkem `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Stopky běžící přes znovunačtení stránky** (`Stopky.KEY`): po obnovení se musí počítat z profilu a zápis po zastavení musí mít částku a měnu profilu. Ověřuje se v prohlížeči v Task 4.

5. **Dvě otevřené karty**: změna profilu v jedné kartě se projeví v druhé (událost `storage`). Kontrola v Task 2.

### Task 1: Logika profilu

**Files:**

**Interfaces:**
- Produces `window.ProfilLogika`:
  - `KEY` = `"zachodova-profil-v1"`, `AVATARY` (pole 8 emoji v pořadí z Global Constraints), `MENY` = `["CZK","EUR","USD"]`, `MAX_PREZDIVKA` = 24.
  - `vychozi()` → `{ prezdivka: "", avatar: "", mode: "md", castka: 0, mena: "CZK", hodiny: 0, dni: 0 }` (nový objekt při každém volání).
  - `normalizuj(obj)` → úplný profil. Pravidla po polích: `prezdivka` řetězec, oříznutý na 24 znaků (jiný typ → ""); `avatar` jen z `AVATARY` (jinak ""); `mode` "md" nebo "sal" (jinak "md"); čísla přijímají number i číselný řetězec, desetinná čárka jako tečka; `castka` konečné ≥ 0 (jinak 0); `hodiny` 0 až 24 (jinak 0); `dni` celé 0 až 31 (jinak 0); `mena` z `MENY` (jinak "CZK"). Neznámé klíče se zahodí. `null`/ne-objekt → `vychozi()`.
  - `parse(raw)` → `{ profil, chybi, poskozeno }`: `raw === null` → `chybi: true`, výchozí profil; nečitelný JSON nebo ne-objekt (včetně pole) → `poskozeno: true`, výchozí profil; jinak `normalizuj`.
  - `zKalkulacky(raw)` → profil z uloženého řetězce klíče `zachodova-kalkulacka-v1`: `mode` = `s.mode`; `castka` = `s.amounts[mode]`, a když chybí a mode je "md", tak `s.md`; `mena` = `s.cur`; `hodiny` = `s.hours`; `dni` = `s.dm`; vše přes `normalizuj`. `null` nebo nečitelné → `vychozi()`.
  - `serializuj(p)` → `JSON.stringify(normalizuj(p))`.
  - `zaMinutu(p)` → výdělek za minutu: md `castka / (hodiny * 60)`; sal `castka / dni / (hodiny * 60)`; když `hodiny` je 0 nebo (u sal) `dni` je 0, vrací 0.

  - `konstanty`: KEY, `AVATARY` rovno `["🧻","🚽","👑","🦆","💩","🐻","🦄","🚀"]`, MENY, MAX_PREZDIVKA 24.
  - `vychozi`: přesný objekt výše; dvě volání nevrací stejný objekt.
  - `normalizuj`: `{castka:"1250,5", hodiny:"8", dni:"20", mode:"sal", mena:"EUR", avatar:"🦆", prezdivka:"Jan"}` → čísla 1250.5, 8, 20 a ostatní beze změny; `castka:-5` → 0; `hodiny:25` → 0; `dni:20.5` → 0; `dni:32` → 0; `mena:"GBP"` → "CZK"; `avatar:"🐸"` → ""; `mode:"x"` → "md"; `prezdivka` 30 znaků → prvních 24; `prezdivka: 5` → ""; `{foo:1}` → výchozí bez `foo`; `null` → výchozí.
  - `parse`: `null` → `{chybi:true, poskozeno:false}` a výchozí profil; `"{"` → `poskozeno:true`; `"[1]"` → `poskozeno:true`; `"5"` → `poskozeno:true`; platný JSON s `castka:"abc"` → `castka 0`, `chybi:false, poskozeno:false`.
  - `zKalkulacky`: `{"mode":"sal","amounts":{"md":"9000","sal":"80000"},"cur":"EUR","hours":"8","dm":"21"}` → `{mode:"sal", castka:80000, mena:"EUR", hodiny:8, dni:21, prezdivka:"", avatar:""}`; starý tvar `{"md":"9000","cur":"CZK","hours":"8"}` → `mode "md", castka 9000`; `null` a `"{"` → výchozí.
  - `serializuj` + `parse` dá zpět stejný profil.
  - `zaMinutu`: md 9600 Kč, 8 h → 20; sal 96000, 20 dní, 8 h → 10; hodiny 0 → 0; sal s dni 0 → 0.

### Task 2: Ikona a vrstva profilu

**Files:**
- Modify: `index.html` (CSS, HTML ikony a vrstvy, nový blok `<script id="profil-ui">` hned za `profil-logika`)

**Interfaces:**
- Consumes: `window.ProfilLogika` (Task 1), `window.Vrstvy.open(el, {returnFocus, initialFocus, onClose})` / `close(el)`.
- Produces `window.Profil`:
  - `aktualni()` → kopie aktuálního (normalizovaného) profilu.
  - `zaMinutu()` → `ProfilLogika.zaMinutu(aktualni())`.
  - `otevri(opener)` → otevře vrstvu; fokus se po zavření vrátí na `opener` (výchozí ikona).
  - `poZmene(fn)` → zaregistruje posluchače volaného bez argumentů po každé změně profilu (úprava ve formuláři i událost `storage`).

**HTML:**
- Hned za `<div class="clock" id="clock">`: `<button type="button" class="profil-btn" id="profilBtn" aria-label="Profil" title="Profil"><span id="profilBtnAvatar" aria-hidden="true"></span></button>`. Bez avataru ukáže jednoduchou SVG ikonu uživatele (hlava a ramena, `currentColor`), s avatarem emoji.
- Vrstva za ostatní vrstvy (za `#porada`): `<div id="profil" class="vrstva profil" tabindex="-1" role="dialog" aria-modal="true" aria-labelledby="profilTitul" hidden>` s hlavičkou ve stylu `.hra-hlava` (nadpis `Profil`, tlačítko `#profilZavrit` „×“ s `aria-label="Zavřít profil"`) a obsahem:
  - náhled: velký avatar `#profilNahledAvatar` a přezdívka `#profilNahledJmeno` (bez přezdívky text „Bez přezdívky“);
  - `<label for="profilPrezdivka">Přezdívka</label>` + `<input id="profilPrezdivka" maxlength="24" autocomplete="nickname">`;
  - `<fieldset>` s legendou „Avatar“ a radio `name="profilAvatar"`: hodnota "" s popiskem „Žádný“, pak 8 emoji (každé s `aria-label` českým názvem: Toaletní papír, Záchod, Koruna, Kachnička, Hovínko, Medvěd, Jednorožec, Raketa);
  - `<fieldset>` s legendou „Pro deník“: radio `name="profilMode"` (`md` „MD sazba“, `sal` „Měsíční plat“), částka `#profilCastka` (label „MD sazba“ / „Měsíční plat“ podle režimu) s výběrem měny `#profilMena` (Kč, €, $), `#profilHodiny` (Délka pracovního dne, hod), `#profilDni` (Pracovních dní / měsíc; celé pole skryté v režimu md), krátká nápověda „Podle toho se počítají zápisy ze stopek. Starší zápisy se nemění.“;
  - tlačítko `#profilHotovo` „Hotovo“ (zavře vrstvu).

**CSS:**
- `.profil-btn`: `position: fixed`, stejný `top` jako `.clock`, kulaté (≈2.1rem, ≥ 44px dotyková plocha přes padding nebo min-size podle stávajícího stylu), `background: var(--porcelain)`, `box-shadow: var(--shadow)`, `z-index: 6` (vrstvy mají 50, takže je zakryje). Umístění: na místě, kde dnes končí hodiny vpravo; `.clock` posuň vlevo o šířku tlačítka + mezeru. Na 320 px i se stopkami v liště se nesmí překrývat (zmenšení u `.clock` pro `max-width: 360px` už existuje; uprav jen posun).
- Vzhled formuláře vrstvy podle stávajících `.field`, `.input-row`, `.seg`; obsah vrstvy scrollovatelný, max. šířka jako panel.

**Chování (`profil-ui`):**
- Start: `ProfilLogika.parse(localStorage.getItem(KEY))`. Když `chybi`, profil = `zKalkulacky(localStorage.getItem("zachodova-kalkulacka-v1"))` a hned se uloží. Když `poskozeno`, výchozí profil v paměti, nic se neukládá (příznak `poskozen = true`).
- Každý `input`/`change` ve formuláři: přečti formulář, `normalizuj`, ulož (`serializuj`), `poskozen = false`, překresli ikonu a náhled, zavolej posluchače `poZmene`. Zápis do localStorage v `try/catch`.
- Do formuláře zapisuj hodnoty jen při otevření a při události `storage` (ne při psaní, aby se nepřepisoval rozepsaný text).
- `storage` s `e.key === KEY` (nebo `null`): znovu `parse`; když není `poskozeno`, převezmi, překresli ikonu, náhled i formulář (pokud je vrstva otevřená), zavolej posluchače.
- Ikona: `aria-label`/`title` „Profil“, s přezdívkou „Profil: Přezdívka“.
- Otevření: `Vrstvy.open(el, { returnFocus: opener || ikona, initialFocus: #profilPrezdivka })`. `#profilZavrit` a `#profilHotovo` → `Vrstvy.close(el)`. Esc a tlačítko Zpět řeší `Vrstvy`.
